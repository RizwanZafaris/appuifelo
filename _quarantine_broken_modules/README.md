# Quarantined Kimi-generated mobile additions

These files were generated by the Kimi swarm but reference providers,
locales, and APIs that don't exist on `main`. They are kept here so future
fix-ups can iterate on them without polluting `main` builds.

`analysis_options.yaml` excludes this folder. Generated `.g.dart` files
are gone because their owners are quarantined.

To re-enable a feature:
1. Move the dir back to `lib/features/<name>/`
2. Add missing locale strings to `lib/l10n/app_en.arb` and `app_ur.arb`
3. Add Riverpod providers (`familyRepositoryProvider`, etc.)
4. Run `dart run build_runner build` then `flutter analyze` until clean
5. Restore matching tests from `test-extras/`
